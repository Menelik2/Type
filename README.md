# Type — Bilingual English & Amharic Learning Platform

Professional full-stack language learning platform for English and Amharic (አማርኛ).

## Getting Started

```bash
git clone https://github.com/Menelik2/Type.git
cd Type
npm install
npm run dev
```

Open http://localhost:5173
